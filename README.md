# 3D Portfolio

A ring of project cards in 3D. Drag (or use the arrow keys) to spin it, click a card to open the live demo.

**Live:** https://ivankuper.github.io/portfolio-3d/

- One `index.html`, no build step. 3D with [three.js](https://threejs.org/).
- The project list is plain HTML links, so the page still works without WebGL or JavaScript, with a keyboard and with a screen reader. The 3D cards are built from that list.
- Works on phones (touch drag) and respects "reduce motion".

To run locally, open `index.html` in a browser.
